# Skaner Studio — wersja na telefon b673 (2026-11-19)

Adres: https://grzepas04-boop.github.io/skaner-iphone-offline/?offline=1&v=673

- **Przełączanie narzędzi**: kliknięcie innego narzędzia (Wybierz, Przesuń, Obróć, Skaluj, Wyciągnij, Napis, Lasso…) albo innej zakładki zamyka poprzednie narzędzie — jego pasek znika i nie przechwytuje już kliknięć. Wcześniej po „Wyciągnij” albo „Napis” opcja „Wybierz” nie działała.
- Ponowne kliknięcie aktywnego narzędzia wyłącza je — masz zwykłą mysz (obracanie widoku i zaznaczanie brył).
