# Skaner Studio b115

- „Rysowanie wieloosiowe” jest teraz widocznym, głównym przyciskiem narzędzia Rysuj 3D.
- Jedna sesja pozostaje aktywna podczas przełączania widoków PRZÓD, BOK, GÓRA, TYŁ, LEWA i DÓŁ.
- Zmiana widoku zachowuje wspólny środek oraz skalę bryły i automatycznie przygotowuje następny rzut.
- Licznik na przycisku pokazuje liczbę zapisanych rzutów tej samej bryły.
- Dopiero „Zamknij bryłę” scala rzuty, zapisuje jeden model i kończy sesję.
- Naprawiono przypadek, w którym zmiana widoku przerywała rysowanie lub przesuwała płaszczyznę kolejnego szkicu.

Wersja offline zawiera 16 zweryfikowanych zasobów, w tym lokalny silnik geometrii WASM.
